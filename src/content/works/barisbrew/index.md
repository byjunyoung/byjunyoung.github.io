## PROBLEM

바리스타 로봇 카페 Baris Brew는 고객이 만나는 접점이 여럿입니다. 키오스크나 모바일 앱으로 주문하고, 전면 디스플레이에서 제조 현황을 확인하고, 픽업존에서 음료를 받습니다. 운영자는 백오피스 BarisON에서 메뉴·재고·기기 상태를 관리합니다. 접점마다 화면과 규칙이 따로 만들어져 있어, 한 번의 주문이 하나의 흐름으로 이어지지 않는 지점이 있었습니다.

현장에서 확인한 문제는 구체적이었습니다. 쿠폰을 찾기 어렵고, 쿠폰 적용 안내가 결제 버튼을 가렸습니다. 대기 주문이 많아지면 주문번호가 돌아가며 표시돼 고객이 대기 시간을 가늠하기 어려웠습니다. QR 인식기 위치가 분명하지 않아 헤매는 고객도 있었습니다. 백오피스는 화면 초안과 일부 개발이 먼저 진행돼, 정보 구조와 권한 체계 같은 기획이 비어 있었습니다.

## APPROACH

2025년 8월 합류하면서 고객 채널과 운영자 백오피스를 하나의 시스템 UX로 묶는 역할을 맡았습니다.

**현장에서 시작:** 박람회 운영 디브리프와 매장 운영 담당자 인터뷰로 문제를 모았습니다. 2026년 여름에는 매장 현장 관찰 리서치를 진행해, 매장별 사용 패턴과 인사이트를 보고서로 정리해 전사에 공유했습니다.

**접점을 가로지르는 흐름 설계:** 주문·결제·제조 안내·픽업·회수까지 한 주문의 상태를 정의하고, 앱·키오스크·디스플레이가 같은 상태를 같은 문구로 보여 주도록 맞췄습니다.

**UX 트랙 운영:** 기획서와 Figma를 분리해 관리하고, 단계별 핸드오프 일정과 주간 회의로 개발팀·AI팀과 진행을 맞췄습니다. 2025년 10월부터는 UX 파트가 PM 역할을 함께 맡았습니다.


## SOLUTION

### 고객 채널

**키오스크:** 쿠폰 흐름을 QR 스캔, 상품 자동 담김, 메뉴 수정, 결제 순으로 줄이고, 결제 수단 선택과 안내 화면을 통합했습니다. 배리어프리 키오스크는 무인단말기 접근성 기준에 맞춰 기존 폼팩터를 유지한 채 물리 키패드·음성 안내·고대비·확대를 더했고, TTS 타이밍과 포커스 순서, 스크린리더 대응을 검수했습니다.

**모바일 앱:** 선주문과 픽업 알림을 중심으로 앱 업데이트를 관리하고, 온도별 가격 옵션을 추가했습니다.

**픽업존·전면 디스플레이:** 제조 현황 안내와 픽업 직후의 피드백을 설계하고, 회수·폐기 상황의 문구를 앱과 디스플레이에서 통일했습니다. 픽업존 화면은 모션과 표기를 줄여 단순하게 유지했습니다.

### 운영자 백오피스 BarisON

무인 매장을 본사가 원격으로 운영·관제하는 콘솔로 BarisON의 방향을 정의했습니다. 운영 담당자 인터뷰를 바탕으로 매장·로봇 원격 제어(전원·상태·카메라), 본사 마스터와 지점 판매 상품·재고의 일원 관리, 결제·매출 분석, 운영 관점의 중요도로 정리한 알람 체계, 본사 관리자·운영 담당자·매장 점주의 3단계 계정 체계를 기획했습니다. 입력 폼 검증과 버튼 라벨 표기 기준 같은 공통 정책도 세웠습니다.

![](./06.jpg)

### VoiceOrder

LLM 기반 음성 주문 서비스의 프롬프트와 대화 흐름을 설계했습니다. 성격·환경·말투·목표·가드레일·도구를 정의한 프롬프트, 호출어("바리스", "안녕, 바리스"), 말 끼어들기 허용, 세션 종료 규칙과 완료 화면까지 다뤘습니다. 매장 시범 운영에서 나온 문제(TTS 소리가 마이크로 되돌아가 끼어들기를 오작동시키는 현상 등)는 체크리스트로 관리하며 업데이트했습니다.


## IMPLEMENTATION

**문서화와 핸드오프:** 2026년부터 제품별 PRD(키오스크·BarisON)를 세워 기능·정책을 Figma 페이지와 1:1로 대응시키고, 변경 이력을 남기며 관리했습니다. 단계별 핸드오프로 개발에 넘기고, BarisON 프로젝트 회의를 주최해 개발팀과 우선순위를 조율했습니다.

**검증:** 매장 시범 운영 체크리스트, 배리어프리 키오스크 QA, 음성 주문 로그 분석으로 설계를 검증했습니다. 로그에서 음성 비서처럼 쓰는 사용 패턴을 발견해, AI 성능이 아니라 UI 문제로 되짚어 보기도 했습니다.


## IMPACT

- 모바일 앱 업데이트를 신규 매장 오픈 일정에 맞춰 배포했습니다.
- VoiceOrder MVP를 2025년 12월 매장 시범 운영에 적용하고, 호출어 인식과 TTS를 개선한 업데이트를 냈습니다.
- BarisON의 재고 관리·결제 관리 개선을 적용했고, 배리어프리 키오스크 스펙을 확정했습니다.
- 매장 현장 관찰 리서치 결과를 전사에 공유했습니다.
