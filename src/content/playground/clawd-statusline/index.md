Claude Code 안에 이미 들어 있는 마스코트 Clawd를 상태줄에 세웠습니다. 컨텍스트와 사용량이 얼마나 남았는지에 따라 자세가 바뀝니다.

출발점은 사라진 `/buddy`였습니다. 자라지도 않았고, 쓰는 방식과 아무 상관이 없었습니다. 그래서 반응의 근거를 실제 사용량에 두었습니다.

쓰던 상태줄을 바꾸지 않고 감싸는 방식이라 더할 때 잃는 게 없습니다. 자세는 Anthropic이 그린 원래 네 가지만 씁니다. 직접 그린 표정은 짝퉁처럼 보여서 뺐고, 레벨 카드와 옷장, 새 캐릭터 세 종도 만들었다가 접었습니다. 한 번 도는 데 0.027초입니다.
