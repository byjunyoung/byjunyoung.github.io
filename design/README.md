# design

byjunyoung.github.io 의 화면을 doan 화면 파일로 옮겨 적은 것. 정본은 사이트 코드이고, 여기는 따라 적는 쪽이다(레포 AGENTS.md "디자인 파일" 절).

- `screens/` 화면 8장(페이지 유형 7) · `tokens/` global.css 값의 DTCG 파일 · `components/` 사이트 부품 계약 + 기본 세트
- doan은 npm이 아니라 로컬 소스를 쓴다(`~/Documents/Claude/doan`).

```bash
node ../doan/src/cli.js lint design
node ../doan/src/cli.js serve design --port 4880
```
